# OptiScaler FSR-RR

面向 Windows 游戏的 OptiScaler 衍生版本，聚焦于 **FSR Ray Regeneration（FSR-RR）** 的集成体验、易用的新菜单布局，以及简体中文界面。

> 本项目为社区维护的衍生版本，与 AMD、NVIDIA、Intel 或游戏开发商无隶属关系。请仅在你拥有和被允许修改的游戏环境中使用。

## 本版本重点

- **FSR-RR 1.2.0 支持**：适配 FSR Ray Regeneration 1.2.0 的资源与输入路径，可在支持 DLSS Ray Reconstruction 的场景中使用 FSR-RR 后端。
- **全新侧栏式 UI**：使用左侧导航与右侧内容面板取代旧式密集双栏排布；各类选项按功能分组，便于快速定位。
- **简体中文翻译**：菜单提供 English / 中文 语言选项，并自动合并 Windows CJK 字体以正确显示中文字符。

## 新 UI 布局

菜单采用“**导航侧栏 + 可滚动内容区**”的结构：

| 区域 | 内容 |
| --- | --- |
| 左侧导航 | Upscaling、Frame Gen、Image、Latency、Display、Advanced、Settings 等分类；当前页面使用强调色标识。 |
| Ray Regeneration | 当游戏正在使用 DLSS-RR 且已路由到 FSR-RR 后端时，自动显示独立的 **Ray Regeneration** 页面。 |
| 右侧内容区 | 以卡片和分组方式展示当前分类的设置；内容较多时可垂直滚动。 |
| 设置页 | 集中提供语言、UI 缩放、保存设置和关闭菜单等操作。 |
| 底部状态区 | 显示渲染/输出分辨率、帧率信息，以及快捷的语言与 UI 缩放控制。 |

新版导航提供悬停反馈、图标、圆角卡片和可配置的强调色；菜单缩放范围为 0.5–2.0，也可保持自动缩放。

## 简体中文

打开游戏内菜单后，进入 **Settings → Language**，选择 **中文** 即可切换简体中文界面。语言选择会写入 `OptiScaler.ini`，下次启动时自动恢复。

若系统安装了微软雅黑、宋体或等线等常见 Windows 中文字体，菜单会自动加载相应 CJK 字符，避免中文显示为方块。若使用自定义字体，请确认其包含所需的中文字符。

## FSR-RR 1.2.0

本分支包含 FSR-RR 1.2.0 的适配工作：

- 处理 1.2.0 所需的 `pNext` 资源描述链；
- 支持独立的间接漫反射与间接镜面反射信号；
- 提供 Ray Regeneration 专属页面，用于访问去噪模式、时序稳定性、辐射限制和调试视图等高级选项；
- 在检测到已安装版本与目标版本不一致时，在菜单中显示版本提示。

> 兼容性取决于具体游戏、渲染 API、驱动和游戏对 DLSS-RR 的实现。FSR-RR 不适用于所有游戏；在游戏运行期间切换游戏内 DLSS-RR 开关后，如出现黑屏或异常，请重启游戏。

## 配置与使用

- 主配置文件：`OptiScaler.ini`
- 菜单内修改后，请使用 **Save Settings** 保存。
- 详细配置项说明请参阅 [Config.md](Config.md)。
- 问题排查和已知限制请参阅 [Issues.md](Issues.md)。

建议在更改 DLL、INI 或渲染相关选项前备份游戏目录中的原始文件与配置。

## 构建

使用 Visual Studio 打开 `OptiScaler.sln`，选择所需的 `x64` 配置后生成。构建产物和临时日志不应提交到仓库。
